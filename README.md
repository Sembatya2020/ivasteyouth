# Ivaste Youth Talents Organization

An informational website for Ivaste Youth Talents Organization, an organization in Uganda empowering orphaned and underserved youth through music, arts education and community outreach.

## Pages

- `index.html`: Organization introduction, programs and ways to get involved.
- `about.html`: Mission, creative arts approach and community outreach.
- `donate.html`: Information for people interested in supporting, volunteering or partnering.
- `contact.html`: Public contact details and social links.
- `thankyou.html`: Thank-you page.

## Run locally

This is a static HTML and CSS website and does not require npm dependencies. From the project folder, run:

```powershell
python -m http.server 8080 --bind 127.0.0.1
```

Then open `http://127.0.0.1:8080/` in a browser.

## Assets and styling

- `style.css` contains the responsive layout and styling.
- `images/ivaste-logo.png` and the program photos are sourced from the organization's official website.
- The visual design keeps the site's dark background, bright green accent and Trebuchet MS font.
